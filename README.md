## How it works

`main.ts` is a small deterministic Node program: it writes that one line (132 characters, no trailing newline) to `/output/entry.txt`. No network, no secrets, no randomness — two runs produce byte-identical output.

```sh
node main.ts   # writes /output/entry.txt
```
